# DSA Visualizer by Cellar

[Launch DSA Visualizer](https://suryandugy-glitch.github.io/dsa-visualizer/) · [Report an issue](https://github.com/suryandugy-glitch/dsa-visualizer/issues)

Choose a sorting algorithm and enter 5, 3, 8, 1. Advance one step at a time to follow each comparison.


[Open the live visualizer](https://suryandugy-glitch.github.io/dsa-visualizer/)

Learn how sorting, searching, and basic data structures work by stepping through
their operations. Use a generated list or enter up to 50 comma-separated whole
numbers from 0 to 999,999. Searching looks for the value 50.

- Sorting includes bubble, insertion, merge, quick, heap, and radix sort.
- Searching includes linear and binary search.
- Data structure demonstrations cover arrays, linked lists, stacks, and queues.
- Play at an adjustable speed or step forward one operation at a time. Reset
  returns to the beginning of the current example.

## Run locally

Use Node.js 22 and npm.

    npm ci
    npm run dev
    npm test -- --run
    npm run build

GitHub Actions tests and publishes the production build when changes land on
\`main\`.
